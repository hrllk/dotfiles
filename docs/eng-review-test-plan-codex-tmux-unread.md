# Test Plan: AI agent tmux unread state

Generated by /plan-eng-review on 2026-07-26
Branch: main
Repo: hrllk/dotfiles

## Affected Pages/Routes

- Not applicable. This is a local tmux integration shared by Codex and Claude Code.

## Key Interactions to Verify

- Completion in an inactive window shows the foreground accent.
- Completion in the active window leaves no unread accent.
- Selecting an unread window clears its state.
- Client focus-in clears the current window state.
- Reloading configuration does not duplicate named hook entries.
- Codex and Claude Code write the same `@ai_unread` flag, and either agent's read event clears the other's mark.

## Edge Cases

- An agent executes outside tmux.
- The originating pane is gone before the Stop hook runs.
- The tmux server is unavailable.
- Two windows complete independently.
- The same window receives multiple completion callbacks.
- The hook runs twice after configuration reload.
- The hook is invoked without an agent label.
- The hook exits non-zero. Claude Code reads exit code 2 on `Stop` as "keep going", so every path must return 0.

## Critical Paths

1. Create an isolated tmux server with two windows.
2. Mark window B complete while window A is active.
3. Assert window B is unread and its status format contains the accent.
4. Select window B.
5. Assert `@ai_unread` is cleared and the original style is restored.

Implemented as `scripts/tests/tmux-unread-test.sh`, wired into
`scripts/tests/post-refactor-smoke-test.sh` and, when the dotfiles checkout is
present, into the Codex harness `ai/.codex/scripts/test`.
